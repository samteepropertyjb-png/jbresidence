# SEO Strategy — The JB Residence

Last updated: 2026-09-30

## Business Goal
The website exists to generate qualified property enquiries.

Primary funnel:
SEO/GEO Article -> Organic/AI traffic -> CTA -> Project Page -> WhatsApp -> Enquiry -> Viewing -> Deal

## Core Strategy
1. **Article-first acquisition.** SEO/GEO articles are the main traffic engine.
2. **Project Pages are conversion pages.** They do not need to rank. Build them well, keep facts accurate, and use articles to send relevant buyers to them.
3. **Do not decide "money content" in advance.** Publish useful content, measure Search Console performance, then strengthen winners with internal links, relevant Project Pages and stronger CTAs.
4. **Evergreen first.** Avoid unnecessary years such as 2026/2027 in core titles and URLs. Prefer evergreen URLs/topics and update the same article when facts change.
5. **SEO + GEO.** Articles should be useful both for Google Search and AI answer/recommendation systems.
6. **Decision content over portal head terms.** Avoid competing head-on with property portals for generic terms such as "Iskandar Puteri property for sale". Prefer buyer questions, comparisons and decision queries such as "Horizon Hills vs Eco Botanic" and "Is Forest City worth buying?"
7. **Research before production.** Do not invent keywords. Validate content opportunities using Google Search Console, Google Trends/related demand signals, live SERPs/competition and commercial relevance.
8. **Simple English.** Default to clear secondary-school-level English. Short sentences, common words, useful headings and tables. Do not use complex language just to sound professional. Write for real buyers first; do not keyword-stuff.

## Fact-Check Rule
Any factual claim that can change or materially affect a buyer's decision must be checked before publishing. Examples:
- project price, rebate and availability
- foreign-buyer rules and minimum purchase price
- tax, stamp duty, RPGT, financing or loan rules
- RTS/transport status and dates
- developer, tenure, completion date
- school/location/distance/commute claims
- rental, transaction and market-price data

Use reliable/current sources for research. If a material fact cannot be confirmed, do not guess. Flag it for verification before publishing.

## Link Policy — HARD RULE
- Default to **internal links only** on The JB Residence.
- Link articles to relevant The JB Residence articles, area pages and Project Pages.
- **Never add clickable external links** to developers, property portals, competitors, news sites, government sites or other third-party sites unless Sam explicitly approves it.
- External websites may be used for research and fact-checking.
- When attribution is useful, write the source name in plain text (for example, "Source: Johor State Government") without making it a clickable external link.
- Exception: Sam's own YouTube videos/channel may be linked or embedded when Sam provides or approves them.
- When improving an existing article, preserve useful internal links unless there is a clear reason to replace them.

Rule summary: **Research externally. Cite source names when needed. Link internally.**

## Improvement Framework
Classify existing articles as:
- KEEP — healthy; no urgent change
- IMPROVE — has search visibility but needs better intent match, CTR, structure or clarity
- EXPAND — good topic with room to cover related buyer questions
- MONETIZE — winner that should receive stronger CTA/project/internal-link treatment
- MERGE — overlapping/cannibalising content
- LOW PRIORITY — weak opportunity for now

Priority order:
1. Existing winners
2. Striking-distance pages/queries (roughly positions 5–20)
3. Content gaps in commercially important clusters
4. New content only after keyword/SERP validation

## Current Strategic Clusters
- **Iskandar Puteri Landed:** existing strength; maintain and expand decision/comparison content.
- **JB Town High-Rise:** currently weaker; build a decision-content cluster rather than generic "condo for sale" content.
- **Forest City / Foreign Buyer / Family & Schools:** authority/information topics that can attract both Search and AI discovery, then route relevant readers to internal pages.

## Measurement
Review approximately every two weeks using new Google Search Console exports.

Track:
Impressions -> Average Position -> Clicks -> CTR -> CTA/Project Page clicks -> WhatsApp enquiries -> Viewings -> Deals

Keep historical snapshots. Never overwrite prior baseline data. Compare period-to-period and record what changed.

## Winner Workflow
Publish/maintain -> Measure -> Identify winner -> Improve search intent/CTR -> Add useful depth/FAQ/GEO structure -> Add relevant internal links -> Add relevant Project Pages -> Improve CTA -> Measure again.
