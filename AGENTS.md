# AGENTS.md — The JB Residence

## SEO / Content Work
Before doing any SEO, GEO, article writing, article improvement, internal-link work, keyword research or content planning:

1. Read `SEO_STRATEGY.md` in full.
2. Read the latest entries in `SEO_WORKLOG.md`.
3. Follow the permanent rules in `SEO_STRATEGY.md`, especially:
   - article-first acquisition
   - Project Pages as conversion pages
   - keyword/SERP research before new content
   - evergreen-first topics/URLs
   - simple secondary-school-level English
   - fact-check material facts before publishing
   - internal links only by default; no clickable third-party external links unless Sam explicitly approves
   - Sam's approved/provided YouTube is the external-link exception
4. Do not invent facts, prices, rules, distances, dates, search volume or keyword demand.
5. After a meaningful SEO review or strategy decision, append a dated summary and next action to `SEO_WORKLOG.md`.
6. Preserve historical GSC baselines so future reviews can compare performance over time.

If an instruction conflicts with a newer explicit instruction from Sam, follow Sam's newest instruction and update the strategy/worklog when the change is intended to be permanent.

## Git Sync Rule
Before SEO or website work, check the branch and working tree, then safely fetch and reconcile with `origin/main`. Preserve local work, never force-push, and never discard changes to make a pull easier. Review, commit and push each completed logical unit so GitHub remains the source of truth.
